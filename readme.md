# Ice Cubes

Refreshing and crunchy take on the vanilla textures :3

> [!IMPORTANT]
> For the best experience install [Polytone](https://modrinth.com/mod/polytone), [MoreMcmeta](https://modrinth.com/mod/moremcmeta), and [Fusion](https://modrinth.com/mod/fusion-connected-textures).

### Features that depend on Polytone:
- Tintable soil

### Features that depend on MoreMcmeta:
- GUI hearts under absorption effect

### Features that depend on Fusion:
- Farmland texture randomization

### Supports:
- AppleSkin
- Raised
- Clutter No More
